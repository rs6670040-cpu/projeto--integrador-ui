Nova oficina

Descreva a oficina, escolha os materiais e monte o passo a passo que os alunos vão seguir.

Rascunho: só você vê. Inscrições abertas: os alunos podem participar. Encerrada: continua visível, sem novas inscrições.

Para quais anos?

Materiais necessários

Marque os materiais e diga quanto cada aluno usa. Para materiais compartilhados, use uma fração (0,25 = um para cada quatro alunos). Isso alimenta a estimativa de itens reaproveitados nos relatórios.

Aparece em destaque para os alunos. Deixe claro o que é feito só por adultos.

Passo a passo

Os alunos marcam cada passo conforme avançam. Use frases curtas e diga quando é preciso chamar o professor.
